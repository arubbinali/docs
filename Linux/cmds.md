# Linux commands

1. **history**  
   Shows a list of previously executed commands in the current shell session.

2. **du -h**  
   Displays disk usage of files and directories in a human-readable format (KB, MB, GB).

3. **df -h**  
   Shows filesystem disk space usage in a human-readable format.

4. **chown [owner]|[group] [file/directory name]**  
   Changes the ownership of a file or directory to a specified user and/or group.

5. **chmod [3 digit binary] [file/directory name]**  
   Changes file or directory permissions using numeric codes (e.g., `755`, `644`).

6. **mkdir [directory name]**  
   Creates a new directory.

7. **rm [file/directory name]**  
   Removes a file or directory. Use `-r` to remove directories recursively.

8. **rm -rf [directory name]**  
   Forcefully removes a directory and all its contents recursively **without confirmation**.  

9. **su - [user name]**  
   Switches to another user account and loads that user’s environment.

10. **SAPCAR -xvf [source] -R [destination]**  
    Extracts a `.SAR` or `.CAR` archive file to the specified destination.

11. **cp -rp [source] [destination]**  
    Copies files/directories recursively and preserves attributes (permissions, ownership, timestamps).

12. **top**  
    Displays running processes in real time, along with CPU and memory usage.

13. **watch**  
    Repeatedly executes a command at fixed intervals and shows the output (default: every 2 seconds).
